## How to Use

1. **Follow the order** — Each part builds on the previous.
2. **Read the README** in each folder for theory.
3. **Run examples** — `node path/to/example.js`
4. **Complete exercises** — Try before peeking at solutions.

## Quick Run

```bash
# From repo root, run any example:
node javascript/oop-complete-guide/01-objects-and-literals/examples/01-simple-object.js
```

## Prerequisites

- Basic JavaScript (variables, functions, arrays)
- Node.js (for running `.js` files)

## The Four Pillars of OOP

- **Encapsulation** — Bundle data and methods; control access.
- **Abstraction** — Hide complexity; expose simple interface.
- **Inheritance** — Reuse code via parent-child relationships.
- **Polymorphism** — Same interface, different behavior.
